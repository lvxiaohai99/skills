# code-detailed-design-report — 怎么测

需要：**指定代码目录** + **用户的 Word 详设模板**（本测试位不入库真实模板与源码）。

1. 把模板放到本机路径（不要提交含公司红头的 docx，除非用户明确要求）。
2. 用 `prompts.md` 话术，带上代码路径与模板路径。
3. 结果：`<软件名>软件详细设计报告_<模块>模块_<版本>.docx` 与同名 `.md`。

## 验收清单

- [ ] 章节标题与模板 Heading 一致，无【模板说明】【示例】
- [ ] md 与 Word 同一套事实；图在 md 里是 mermaid
- [ ] 边界图模块名与架构文档字面一致
- [ ] 未把代码里没有的接口写进去
