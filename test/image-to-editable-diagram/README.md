# image-to-editable-diagram 测试

把参考图放进 `inputs/`，把生成结果放到 `outputs/`。

## 建议测什么

1. **高保真**：截图 → HTML+SVG（文字、虚实线要对）
2. **可演示**：截图 → PPTX（能在 PowerPoint / WPS 里改）
3. **可再编辑**：截图 → draw.io（能拖节点、连线跟着走）
4. **逻辑稿**：截图 → Mermaid（`.mmd` 能渲染）

## 操作步骤

1. 把图片放到 `inputs/`（png / jpg / webp 均可）
2. 对 AI 说下面「测试话术」里的任意一句
3. 在 `outputs/` 打开结果，对照原图检查

详见上级 `../README.md`。
