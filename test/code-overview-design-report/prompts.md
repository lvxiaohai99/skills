# code-overview-design-report — 测试话术

## 1. 只要 Markdown（无 Word 模板）

用 code-overview-design-report，根据代码 `<你的模块路径>`，
模块名 DVR（或实际名），只要 Markdown 概要设计报告，
保存到 `test/code-overview-design-report/outputs/`。

## 2. 按 Word 模板

用 code-overview-design-report，根据代码 `<你的模块路径>`，
按模板 `<你的概设模板.docx>` 生成概要设计报告，Word 和 Markdown 都要，
保存到 `test/code-overview-design-report/outputs/`。
