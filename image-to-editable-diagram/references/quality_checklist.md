# 质量检查清单（交付前逐项确认）

## A. 读图准确性（最易翻车）
- [ ] 已用 `scripts/prepare_image.py` 分区放大，**逐块**读过密集/低清区域，
      而非只看整图一眼。
- [ ] 标题一字不差抄录（含括号里的副标题）。
- [ ] 每个模块、每条括号补充说明、目录树/代码块的每一行都已还原。
- [ ] 图例文字与分类颜色全部抄录。
- [ ] 无凭空臆造的内容——只要看不清就再放大，绝不猜测填充。

> 教训：低清密集图直接整图识别极易**整体看错主题**。放大分区读是强制步骤。

## B. 逻辑一致性
- [ ] 箭头**方向**与原图一致。
- [ ] **实线/虚线**区分正确（虚线常表示预留/逻辑/状态回传）。
- [ ] 连线**颜色分组**与图例对应（不同通道/子系统）。
- [ ] 分组容器（虚线域/实体域）的归属与嵌套关系正确。
- [ ] 步骤编号（1./2./3.…）顺序与位置正确。

## C. 排版质量
- [ ] 无遮挡：盒子、文字、连线层级正确，互不压盖。
- [ ] 无溢出：文字不超出盒子，节点不超出画布。
- [ ] 画布比例接近原图（避免拉伸变形）。
- [ ] 配色还原原图色系。

## D. 可编辑性交付
- [ ] 交付的是**源码/可编辑格式**（HTML / .mmd / .svg / .pptx），不是图片。
- [ ] HTML 为**单文件自包含**（样式内联，图标用 emoji 或 CDN）。
- [ ] 已用 `scripts/render_html.py` 渲染自检，或说明用户可本地浏览器打开核对。
- [ ] 清理了中间产物（`_zoom/` 放大图等临时文件）。
